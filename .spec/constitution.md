# Project Constitution: Hasan Life Guide

## Non-Negotiable Core Principles
1. **Spec-Driven Development (SDD):** Code is strictly downstream of specification. No code without tasks in `.spec/tasks.md`.
2. **Backend-First Discipline:** Build, structure, and verify the backend database and API layer thoroughly with tests BEFORE building the frontend.
3. **Core Pillars:**
   - **Rich Note-Taking with Voice:** Notes must support rich text/markdown AND integrated voice (voice dictation/speech-to-text + audio voice recordings/attachments).
   - **Voice Everywhere:** Quick voice-capture across the entire app with truthful capability reporting (never fake speech recognition).
   - **Tri-lingual & RTL:** Bengali, Arabic (full RTL), and English localized across all UI text, errors, and system alerts.
   - **Tri-theme:** Dark Mode, Light Mode, and Sophia Mode (luxury glowing cinematic accents with glassmorphism).
   - **Hasan Robot 3D Mascot:** Lightweight, battery-friendly Three.js mascot with 4 states (idle, listening, thinking, speaking) and audio-synchronized mouth movements.
4. **Zero Paid Recurring Dependencies:** $0 operating cost. Offline-first client persistence with local SQLite database and Web Speech API.
5. **Quality & Verification:** Test each layer, verify APIs, validate performance (60 FPS frontend, <50ms local API responses), and confirm before marking complete.
