## 🌟 Overview

**Hasan Life Guide** is an offline-first personal management and mentorship suite. It helps individuals organize their daily routines, track habits, record voice memos, manage expenses, and follow structured life development roadmaps, accompanied by an interactive 3D mascot (**Hasan Robot**).

---

## 🚀 Key Modules

* **🎙️ Voice Memo & Transcription:** Record quick spoken notes with client-side audio processing.
* **🤖 Hasan 3D Robot Mascot:** Reactive mascot providing interactive emotional expressions, motivational quotes, and productivity coaching.
* **🌐 Trilingual & RTL Support:** Seamless switching between Bengali, English, and Arabic/Urdu with bidirectional RTL layout engine.
* **💾 Offline-First Architecture:** Local client persistence with automatic background cloud synchronization upon reconnecting.
* **🧭 Mentorship & Guidance:** Interactive roadmap visualization with milestones for personal and career goals.

---

## 🛠️ Architecture

Monorepo workspace architecture containing:
- `client/`: Modern React + Vite frontend with Tailwind CSS and local persistence layers.
- `server/`: Node.js / Express micro-service for sync and notifications.
